# Доска Miro для каждого ученика

Один серверный токен может читать несколько ваших досок, если приложение Miro установлено в нужной команде и у владельца токена есть доступ к этим доскам. Каждому кабинету назначается собственная ссылка. Для Андрея и Тани можно оставить одну общую доску и кабинет.

## 1. Подключить Miro к серверу

1. Войдите в свой Miro. Откройте официальную инструкцию разработчика: https://developers.miro.com/docs/getting-started-with-oauth . Для личного подключения подходит установка своего приложения в свою команду; публиковать его в каталоге Miro не требуется.
2. В настройках Miro откройте Your apps / Developer apps и создайте приложение. Если раздел недоступен, следуйте предложению Miro создать команду разработчика или обратитесь к администратору вашей команды.
3. В разрешениях приложения включите `boards:read`. Запись на доску приложению не нужна.
4. Установите приложение в команду, где находятся учебные доски, через Install app and get OAuth token (название кнопки зависит от интерфейса Miro). Если меняли разрешения после установки, переустановите приложение.
5. Скопируйте Access token. Это именно токен доступа, а не Client ID и не Client secret. Доступность установки в рабочую команду зависит от её правил и тарифа; одной команды разработчика недостаточно для чтения досок другой закрытой команды.
6. В Render откройте andrey → Environment → Edit → Add variable. Key: `MIRO_ACCESS_TOKEN`; Value: скопированный токен Miro. Кнопка Generate здесь не подходит.
7. Сохраните через Save, rebuild, and deploy и дождитесь успешного запуска. Обновите платформу. Не отправляйте токен в чат, ученикам или в GitHub.

Если Miro выдаёт токен со сроком действия, после истечения его нужно заменить в Render. Автоматическое обновление OAuth-токена и установка приложения для других преподавателей в эту версию не входят.

## 2. Подключить ИИ

Для извлечения слов, тем и примеров нужен `ANTHROPIC_API_KEY`: [пошаговая инструкция](AI_SETUP.md). Render, Miro и API Anthropic оплачиваются отдельно по условиям соответствующих сервисов. Само наличие переменной ещё не подтверждает действительность ключа и доступный баланс.

## 3. Назначить ученику доску и загрузить материал

1. Войдите преподавателем → Мои ученики → Имя и уровень у нужного ученика.
2. Укажите его уровень A1–C2 и вставьте обычную ссылку на доску `https://miro.com/app/board/…`. Сохраните.
3. Откройте кабинет этого ученика → Слова → Загрузить из Miro.
4. Приложение прочитает текстовые объекты доски. Выберите фрагмент и нажмите Разобрать фрагмент с Claude. Передача текста в ИИ происходит после этой кнопки.
5. Проверьте переводы, темы, примеры и список карточек. Снимите отметки с ненужных карточек и нажмите Подтвердить и добавить.
6. Слова появятся в датированном уроке и «Автоматизации». Инфинитивы из отдельных карточек появятся в выборе вкладки «Глаголы»; для отсутствующих таблиц форм используйте существующую генерацию форм с ИИ.

## Что переносится

Переносится текст стикеров, текстовых объектов, заголовки и описания карточек, доступные через API. Изображения, рукопись, аудио, содержимое вложенных PDF и расположение объектов не распознаются. Загрузка сообщает число объектов без доступного текста. Для длинных досок текст разбивается на фрагменты; обрабатывайте и подтверждайте их по очереди. Ограничение загрузки — 200 000 символов и 5 000 объектов.

Это импорт через API по кнопке. Приложение не следит за доской в фоне и не удаляет слова вслед за удалением объектов Miro. Повторно встреченные испанские слова используют уже существующие карточки с сохранением прогресса; существующие переводы автоматически не перезаписываются. ИИ выбирает полезную лексику по материалу и уровню, но не устанавливает статистическую частотность слов.

Токен остаётся на сервере, ученики не могут запускать импорт. При этом обычная ссылка на доску сохраняется в данных кабинета: доступ к самой доске регулируют настройки Miro. Не размещайте материалы других учеников на доске, к которой открыт общий доступ.

## Если загрузка не работает

- Miro не разрешил доступ: проверьте токен, разрешение `boards:read`, команду установки приложения и доступ владельца токена к доске.
- Кнопка недоступна: сохраните ссылку в профиле и переменную в Render, дождитесь успешного Deploy и обновите страницу.
- Доска загрузилась, но ИИ не разбирает: проверьте подключение Anthropic и баланс API.
- На доске нет доступного текста: материал может быть картинками или PDF; их нужно перенести отдельным способом.

Реальное подключение к аккаунту Miro необходимо проверить после добавления вашего токена. В разработке проверены пагинация API, разбор текста, ошибки доступа и весь путь импорта с подставными ответами Miro/ИИ; секреты аккаунта не предоставлялись.
