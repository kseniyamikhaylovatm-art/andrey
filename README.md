# Mi español · Андрей и Таня

Пошаговое пробное размещение сайта: [DEPLOY.md](DEPLOY.md). `render.yaml` использует бесплатный тариф Render с временным хранилищем: прогресс может сброситься после сна/перезапуска. Не вносите туда важные данные. Отдельный `render-persistent.yaml` — платный вариант для постоянного хранения, не применяется автоматически.

Персональный тренажёр с отдельными кабинетами преподавателя и учеников. У Андрея и Тани сохраняется один общий кабинет пары; каждому новому ученику создаётся отдельный кабинет. Русский интерфейс, испанский учебный контент; адаптация для телефона и компьютера.

## Запуск

Нужен Node.js **24** (проверено на 24.19.0), npm и существующая копия репозитория. Дополнительный Git worktree не нужен: облачная задача уже изолирована.

```sh
cd /workspace/andrey
npm ci
npm run dev
```

Сервер по умолчанию слушает `127.0.0.1:3000`. Он обслуживает и интерфейс, и API; отдельные сервисы базы данных не нужны. Проверка работоспособности: `curl --fail http://127.0.0.1:3000/api/health`. Для разработки в другой среде путь к репозиторию может отличаться.

```sh
npm run build     # TypeScript и production-сборка интерфейса
npm test          # 50 тестов: логика, SQLite, HTTP, PDF, роли, изоляция, слова уроков
npm run test:e2e  # Chromium: основные действия и мобильная навигация
npm run test:production # После build: production-сервер, вход и перезапуск с сохранением данных
```

Для браузерных тестов используется `/usr/bin/chromium`. Другой путь можно указать через `CHROMIUM_PATH`. Если Chromium не установлен, установите поддерживаемый браузер Playwright и укажите путь. Браузерные тесты создают собственную временную SQLite-базу и не трогают пользовательские данные.

## Оформление

Тёмно-синяя фактурная шапка с монограммой ñ, золотые акценты, горизонтальная навигация и светлые карточки с мягкой тенью. Крупные заголовки используют локальную Oswald с кириллицей; обращения к внешним сервисам шрифтов не нужны. Девять разделов: «План» остаётся первым, за ним добавлены «Слова». На телефоне меню можно прокручивать или раскрыть, экспорт данных и выход доступны в нём. Кабинет преподавателя показывает действительную статистику текущего пространства и сводку на всю ширину; данные из визуального образца не копируются в базу.

## Что работает

- **Кабинеты и вход:** отдельный личный код преподавателя открывает список всех учеников. Преподаватель создаёт кабинет по имени и уровню, получает случайный код ученика и может заменить его, сохранив прогресс. Код показывается только при выдаче; в базе хранится его хеш. Замена сразу отзывает прежний код и сеансы ученика. Ученик видит только свои данные; сервер запрещает доступ к чужому кабинету и преподавательские изменения. Преподаватель открывает нужного ученика из списка и возвращается кнопкой «Мои ученики». Пустой новый кабинет можно дополнить стартовыми примерами по желанию. Существующий кабинет пары мигрирует автоматически без очистки данных.
- **Главная («План»):** дата, доска месячного плана (два аспекта, скиллы/темы/ситуации, точки А и Б, критерии ученика), рефлексия и архив. При входе ученика приложение предлагает планирование следующего периода; прочие учебные разделы доступны через навигацию.
- **Слова уроков:** преподаватель открывает кабинет ученика → «Слова», выбирает дату и записывает пары «испанское слово — русский перевод» нажатием Enter. Первый ввод создаёт запись урока, если её ещё нет за эту дату; существующий урок можно выбрать из списка. Созданная запись имеет статус «Запланирован»: ввод слов сам по себе не отмечает состоявшееся и не расходует оплату. Урок хранит ссылки на те же карточки, которые используются в «Автоматизации». Повторное слово связывается с новым уроком без дубликата и сброса прогресса; при отличающемся переводе явно сохраняется прежний перевод с возможностью исправления преподавателем. Исправления карточки видны во всех связанных уроках и тренажёре. Удаление слова из записи убирает только связь с этим уроком. Ученик видит собственные списки по датам, переводы, примеры и озвучку, может отмечать слова в фокус и запускать тренировку целого урока. Открытая ученическая вкладка обновляется каждые 8 секунд, пока видима. Импорт файлов и ИИ для записи слов не нужны.
- **Кабинет:** действительная статистика, сводка по данным (без ИИ тоже), трудные фразы, фокус, задания со сроками, дневник реальной речи и доля избегания по неделям, материалы и заметки уроков.
- **Автоматизация:** до четырёх вариантов перевода; если в кабинете только один перевод, вместо единственного очевидного варианта ученик вводит его текстом. Примеры открываются после ответа. Интервалы 1–2–4–8–16–32 дня, после ошибки — 10 минут. Новые слова, повторение, фокус, темы, выбор урока, база с редактированием и включением отдельных фраз. Обычная сессия содержит до 10 карточек, тренировка конкретного урока проходит все его включённые слова. Тренировка дня связывает карточки, письмо форм, речь и слух.
- **Читаемость и звук:** увеличены текст интерфейса, переводы и кнопки ответов (20 px на компьютере, 18 px на телефоне). При начале и переходе к следующей карточке слово автоматически звучит по-испански. У верного ответа короткий восходящий сигнал, у ошибки — отдельный низкий сигнал; сетевая ошибка не озвучивается как неверный ответ. «Автоозвучка слов» и «Звуки ответов» включены по умолчанию и отдельно отключаются, выбор сохраняется в этом браузере. Ручная обычная/медленная озвучка остаётся доступной. Аудио активируется нажатием в тренажёре; уход из него останавливает воспроизведение. Озвучка зависит от голосов браузера/устройства, сигналы синтезируются локально через Web Audio и не требуют ИИ.
- **Примеры под карточкой:** после ответа открываются шесть вкладок: Presente, ir a + infinitivo, estoy + gerundio, pretérito perfecto, indefinido и imperfecto. В каждой — испанский пример, русский перевод, обычная и медленная озвучка; у поддерживаемых глаголов дополнительно шесть форм. Для всех 24 стартовых карточек есть подготовленные примеры без API. Существительные не спрягаются; для состояний не создаётся искусственное estoy estando. Можно добавить или исправить пример выбранного времени, сохранив остальные примеры и прогресс. Исходные примеры без метки времени остаются в раскрываемом разделе материалов. Для нового незнакомого слова пустые вкладки заполняются преподавателем или кнопкой «Дополнить с ИИ» при подключённом ключе; недостающие примеры не выдумываются автоматически.
- **Глаголы:** ручной выбор или ввод инфинитива, настоящее, три прошедших, герундий и будущее ir a + infinitivo, ввод шести форм, проверка ударений, таблица справа и исправления преподавателем. Проверенные стартовые формы 22 глаголов, включая неправильные и возвратный `escaparse`. Для других глаголов доступны ручное заполнение и генерация с Claude.
- **Речь:** монолог, пересказ, работа над ошибками, диалог; текст и браузерная диктовка, таймер; серверная история ответов и диалогов после успешной проверки. Диктовка — распознавание текста браузером, не оценка произношения и не сохранение аудиофайла.
- **Слух:** три стартовых задания с браузерной озвучкой и скрытым до ответа образцом; преподаватель может добавить прямую HTTPS-ссылку на запись. Открытый ответ сравнивается с образцом, а при подключённом Claude получает индивидуальную обратную связь. Открытые ответы не получают искусственную оценку «верно/неверно».
- **Прогресс:** настоящие попытки, точность, активность за 12 недель, темы, прогноз повторений, трудные фразы и времена.
- **Оплата:** количество уроков задаётся отдельно для каждой оплаты, оплаченные строки, состоявшиеся/отменённые встречи, остаток и долг в занятиях. Изменения вносит преподаватель; ученик видит свой учёт без права редактирования. Отмена не расходует пакет. Приложение не принимает деньги.
- **PDF карточек без ИИ:** кнопка «Загрузить PDF карточек» в «Автоматизации» и «Кабинете». Строки «испанское слово — русский перевод» создают до 1000 карточек за раз. Поддерживаются тире/дефис, фразы и вставка списка текстом; перед сохранением — исправление и удаление отдельных строк. Неразобранные строки показаны явно. Повторы пропускаются без замены перевода и прогресса. Этот режим не создаёт занятия и не требует API-ключа.
- **PDF материалов урока:** извлечение текста из текстового PDF до 15 МБ / 150 страниц; выбор страниц, обработка фрагмента Claude, редактируемый предпросмотр и явное подтверждение. Повторные фразы не дублируются, сохраняются источник, регистр и текст урока. Грубые фразы при импорте по умолчанию выключены. Сканированным PDF предварительно нужен OCR.

Стартовые 24 карточки и три задания на слух помечены как учебные примеры. Реальные занятия, оплаты, ответы и прогресс при первом запуске **пустые**. Материал «Clanes» не был предоставлен и не выдаётся за загруженный.

## Подключение Claude

Скопируйте `.env.example` в локальный `.env` и задайте `ANTHROPIC_API_KEY` безопасным способом на сервере. Не сохраняйте ключ в Git и не вводите его в чат. По умолчанию выбран `claude-sonnet-4-5`; `ANTHROPIC_MODEL` позволяет выбрать доступную вашей организации модель.

Ключ используется только сервером. В интерфейс он не передаётся. Нужен HTTPS-доступ к **api.anthropic.com**; npm использует **registry.npmjs.org**. В управляемой облачной среде сохраняется унаследованный HTTP(S)-прокси и доверие TLS; AI-запросы идут через `EnvHttpProxyAgent`. Проверка сертификатов не отключается.

Без ключа ИИ-действия обозначены как недоступные. Приложение не подменяет ответ Claude шаблонной «проверкой». Карточки, стартовые глаголы, редактирование, статистика, дневник, учёт, массовый импорт пар «слово — перевод» и локальное чтение PDF работают независимо от API. Индивидуальный разбор речи, диалоги, генерация новых таблиц/карточек и автоматический разбор документов требуют ключа. Ответы Claude в этой среде не проверены: ключ не предоставлен.

На сервере действует лимит 80 AI-запросов в час на общее пространство и тайм-аут запроса 90 секунд. Преподавателю следует проверять автоматически созданные формы и материалы перед использованием.

## Хранение и общий доступ

Данные находятся в `data/mi-espanol.sqlite` (WAL, транзакции). `DATA_DIR` задаёт другой каталог. Сервер хранит реестр учеников и отдельное состояние каждого кабинета. Подписанная сессия содержит роль и, у ученика, идентификатор его кабинета. Переданный клиентом идентификатор не меняет права ученика. Область данных привязана к запросу через AsyncLocalStorage, включая продолжение асинхронных ИИ-запросов. Черновики речи разделены по кабинету и роли в sessionStorage и очищаются при выходе; сохранённые ответы хранятся на сервере.

Прежнее общее пространство однократно переносится в кабинет `legacy` («Андрей и Таня»); исходная таблица остаётся резервной копией миграции. Старые сессии без роли требуют повторного входа. Прежний `APP_ACCESS_CODE` даёт только ученический доступ к этому кабинету, пока преподаватель не выдаст для него новый код. Он никогда не становится кодом преподавателя автоматически.

Для размещения нужен **один Node-процесс и постоянный диск**. Публикация только папки `dist` не подходит: API и база необходимы. Не запускайте несколько экземпляров с независимыми дисками. Регулярно делайте согласованную резервную копию SQLite (например, через SQLite backup API). В интерфейсе также есть скачивание JSON-экспорта. Автоматического восстановления JSON через интерфейс пока нет.

Production:

```sh
npm ci
npm run build
# Переменные должны быть заданы безопасно в среде размещения:
# TEACHER_ACCESS_CODE — отдельный личный код преподавателя от 16 символов (лучше 32)
# APP_ACCESS_CODE — необязательный прежний код пары от 10 символов; только ученический доступ
# SESSION_SECRET — случайный секрет не короче 32 символов
# DATA_DIR — каталог постоянного диска
# HOST=0.0.0.0 — только за вашим HTTPS-прокси
npm start
```

Production-сервер требует секрет сессии и код преподавателя либо прежний код пары. При отсутствии кода преподавателя старый ученический вход продолжает работать, но управление учениками закрыто до настройки `TEACHER_ACCESS_CODE`. Коды преподавателя и пары должны различаться. Сессия хранится в подписанной HttpOnly/SameSite=Strict cookie, в production — Secure. Все рабочие API и экспорт защищены; экспорт содержит только выбранный кабинет, без кодов. Для тестирования по HTTP используйте `npm run dev`; без обоих кодов только в режиме разработки доступен локальный преподавательский вход. Публичный доступ размещайте через HTTPS.

Это самостоятельное веб-приложение. Оно **не опубликовано в Claude Artifacts**: команда Claude сама по себе не размещает Node-сервер и SQLite и не предоставляет приложению Claude API. После размещения можно делиться HTTPS-ссылкой на приложение. Для нативной публикации внутри Claude нужен отдельный поддерживаемый механизм интеграции. Сайт-образец по предоставленной ссылке вернул 403; дизайн реализован по описанию из ТЗ, без заявления о точном визуальном совпадении.

## Следующие этапы

Для полного курса остаются подключение и проверка реального Claude API, загрузка настоящих материалов и аудиозаписей из Испании, проверка педагогом и постоянное хранилище. Более сложные типы упражнений из PDF (отдельное хранение ключей, четыре уровня понимания, автоматическое создание обратных карточек) и уведомления — следующий этап. Новые кабинеты уже создаются отдельно, без копирования личных ответов другого ученика. Сейчас импорт создаёт карточки, темы, полный текст урока и задания; ключи не включаются в открытые формулировки заданий.

«Автоматизация → Упражнение формат дуолинго»: 13 заданий по включённым карточкам, выбор темы и урока, перевод в обе стороны, ввод, сборка фраз, пропуски и диктант. Форматы зависят от доступного материала; предложения не генерируются ИИ. Ошибки и пропуски повторяются после основного круга. Озвучку можно заменить письменным повторением. Проверка идёт по записанному варианту с учётом испанских ударений. Результаты сохраняются, повторные верные ответы не повышают этап SRS многократно за одну сессию. Незавершённая сессия хранится в памяти сервера до 2 часов и не восстанавливается после перезапуска; уже сохранённые попытки остаются в SQLite.

Во вкладке «Слова» можно вводить только испанское слово. Сервер возвращает сохранённый перевод из текущего кабинета или получает новый перевод через Claude (`ANTHROPIC_API_KEY`). После успешного перевода слово сохраняется в выбранном уроке и в карточках. Слова показаны компактными строками под датой урока; перевод и пример открываются по нажатию. Общий показ переводов можно включить флажком. Без ключа новые слова вводятся парой «слово — перевод»; при ошибке автоперевода ввод сохраняется, пустой урок не создаётся. Реальный платный API в среде разработки не проверен: тесты используют проверяемый ответ-подстановку, секрет не предоставлен.

Во вкладке «Слова» переключатель «Списком» позволяет вставить до 100 пар «испанский — русский», по одной на строку, и сохранить их за выбранную дату одной операцией. Enter создаёт новую строку, Ctrl/⌘+Enter отправляет список. До 50 строк без перевода можно обработать при подключённом ИИ. До получения всех переводов и проверки строк ничего не сохраняется; при ошибке введённый список остаётся в поле. Повторы используют прежние карточки и их прогресс.

Подключение ИИ: [AI_SETUP.md](AI_SETUP.md). Уровень редактируется в «Мои ученики → Имя и уровень» и остаётся общим с планом обучения. ИИ получает рекомендации сложности для текущего уровня во всех запросах. Пример по нажатию на слово сохраняется с уровнем и повторно используется; параллельные открытия одного слова не создают несколько платных запросов. Реальный Anthropic API в среде разработки не проверен: ключ не предоставлен, тесты проверяют инструкции запроса и обработку ответа с подстановкой.

Miro: [инструкция подключения](MIRO_SETUP.md). У каждого ученика своя доска в «Мои ученики → Имя и уровень». Преподаватель загружает текст через API Miro, передаёт выбранный фрагмент ИИ и проверяет черновик перед сохранением. Карточки привязаны к датированному уроку; отдельные инфинитивы доступны в выборе глаголов. Это импорт по кнопке, без фоновой синхронизации и удаления данных при изменении доски. API получает текст объектов, без распознавания изображений и вложенных PDF. Токен хранится только на сервере; ученики не могут запускать импорт. Реальный Miro API ещё не проверен с учётной записью владельца: токен не предоставлен.

Тренировка слов теперь работает через припоминание: карточка сначала молчит и скрывает перевод; «Подсказка» открывает перевод и озвучивает испанское слово. «Вспомнил» / «Не вспомнил» сохраняют самооценку в том же SRS (1/2/4/8/16/32 дня; ошибка — 10 минут). Повторная отправка того же ответа не увеличивает интервал второй раз. Оценка субъективная: приложение не проверяет произнесённый про себя перевод.

После «Вспомнил» звучит сигнал успеха, затем сохранённый пример из кабинета. При отсутствии такого примера и подключённом ИИ запрашивается один пример по уровню ученика, его записанным урокам и словарю; результат сохраняется. Без ИИ и сохранённого примера новая фраза не придумывается. Стартовые примеры в шести временах остаются доступны отдельно, но автоматическое чтение предпочитает примеры карточки. Озвучка и сигналы отключаются переключателями; переход к следующему слову или выход останавливает отложенную озвучку. Настоящие голоса зависят от браузера и установленных голосов устройства; браузерные тесты проверяют порядок обращений к синтезатору и Web Audio.

Вход в «Автоматизацию» теперь открывает три карточки форматов: «Упражнения формат 17 языков», «Упражнение формат дуолинго» и «Формат Анки». База слов доступна отдельной ссылкой. Старый маршрут view=day ведёт на выбор форматов; ссылки на конкретный урок, тему или режим по-прежнему открывают тренировку напрямую. «Тренировка дня» убрана из меню автоматизации; выбор форматов находится во вкладке «Автоматизация».

В «Упражнения формат 17 языков» одна сессия автоматически чередует припоминание с подсказкой и выбор перевода в направлениях испанский → русский и русский → испанский. До четырёх разных ответов берутся из включённой базы этого ученика; совпадающие переводы исключаются. При небольшом словаре показывается доступное число вариантов, при отсутствии двух разных значений выбор недоступен. Ответ проверяется на сервере, влияет на общий SRS и сохраняется один раз при повторной отправке. Ответы ученика не затрагивают другой кабинет.

У вариантов есть небольшие локальные тематические SVG-иллюстрации в цветах платформы. Это иллюстрации темы, а не автоматически сгенерированные точные изображения каждой фразы; для абстрактных выражений используется нейтральная книга. В редакторе карточки преподаватель может указать собственную HTTPS-ссылку на картинку. Ссылка сохраняется в imageUrl; при ошибке загрузки используется локальная иллюстрация. Запросы к сторонним изображениям выполняются браузером без Referer. Сервер их не скачивает. Генерация изображений ИИ в этой версии не подключена.

«Формат Анки»: слово и сохранённый пример → «Показать ответ» → четыре русские оценки. Для нового слова «Ещё раз» назначает 1 минуту, «Трудно» — 6 минут, «Хорошо» — 10 минут, «Легко» — 4 дня. После следующего «Хорошо» учебный шаг переходит к повторению через день. У закрепляемых карточек «Хорошо» повышает этап на один, «Легко» на два; «Трудно» сокращает интервал до 60% текущего, минимум день. Интервалы этапов — 1/2/4/8/16/32 дня. Это простой алгоритм платформы, не реализация Anki FSRS. Даты карточек общие для всех форматов, учебный шаг Анки сбрасывается при ответе в другом формате. После оценки автоматически появляется следующая карточка; короткие повторы доступны в очереди «Повторение», когда наступает их срок. Пример показывается только из сохранённой карточки, с подходящим уровнем или без указанного уровня; блок времён в этом формате не отображается. «Упражнение формат дуолинго» сохраняет свои 13 смешанных заданий и работу над ошибками.

«Кабинет → Слова в базу» открывает загрузку списка по теме. Вставьте пары «испанское — русский», задайте общую тему, проверьте список и подтвердите добавление. Одна загрузка — одна тема; урок и дата не создаются. Карточки доступны в базе и всех тренировках по фильтру темы. ИИ для этого не нужен; переводы должны быть в исходном списке. Можно переключиться на добавление одного слова. Повторы сохраняют прежние переводы и прогресс.

В «Оплате» преподаватель указывает дату, фактическое количество оплаченных уроков (1–1000) и необязательную заметку. Записи можно исправлять; ученик видит свой журнал без права редактирования. В списке учеников показаны суммы оплаченных, проведённых и оставшихся занятий, отрицательный остаток обозначается долгом. Повторная отправка формы с тем же requestId не добавляет оплату второй раз. Это журнал полученных оплат, деньги приложение не принимает.

Ранее записанные оплаты без количества остаются пакетами по 12 занятий и могут быть исправлены преподавателем. Для совместимости старый API-запрос только с датой также означает 12 занятий; новая форма требует явного количества. Сохраняется прежняя граница учёта: вычитаются состоявшиеся занятия начиная с даты первой зарегистрированной оплаты (при отсутствии оплат — все состоявшиеся занятия). Запланированные и отменённые занятия не списываются. Расчёт общий для сервера, страницы оплаты и списка учеников.

«Упражнения формат 17 языков» теперь ведёт единую сессию: припоминание → выбор русского значения → выбор испанского слова, затем цикл повторяется на следующих словах. Выбор темы, урока и очереди SRS сохраняется, отдельных переключателей типа задания нет. Если для выбора не хватает разных значений, шаг заменяется припоминанием. В конце можно включить одну проверку presente для глагола из выбранных слов с готовой таблицей; неподтверждённые формы не придумываются. Сначала формы скрыты, затем ученик раскрывает их и оценивает себя. Проверка форм записывается отдельно от карточного SRS.

При ошибке в выборе перевода вариант раскрывается и блокируется, остальные доступны до правильного ответа. Ошибка назначает повтор через 10 минут; последующее угадывание в этом шаге не повышает этап карточки. Повторные запросы не учитывают один ответ дважды. Для обратного перевода картинки скрыты до выбора, при ошибке показывается значение выбранного испанского слова. После завершённого ответа доступны шкала интервалов, примеры, их озвучка и раскрываемые кнопкой переводы. Переключение вкладки примера запускает его озвучку при включённом звуке.

Сессии принадлежат выбранному кабинету, живут в памяти до двух часов; незавершённая сессия не восстанавливается после перезапуска, уже записанные попытки и интервалы остаются в SQLite. ИИ не нужен для чередования и проверки сохранённых карточек. Новые примеры требуют подключённого API; фотографии и иллюстрации берутся из карточек, изображения из видео не переносятся автоматически.

В кабинете преподавателя и в «Моих уроках» ученика есть «Практика словаря»: отдельные показатели трёх форматов, XP, серия дней, количество ответов и слов, закреплённые/трудные/изучаемые слова, завершённые сессии и последние восемь тренировок. «Закреплено» означает этап 4+ по последнему ответу в конкретном формате, «Ещё сложно» — последнюю ошибку или оценку «Трудно»/«Ещё раз». Числа отражают практику, а не объективную проверку долговременного запоминания.

За первое завершённое упражнение с каждым словом в каждом формате за день начисляется 10 XP; честная самооценка «Ещё раз» тоже награждается. Неверный выбор до завершения задания XP не добавляет. Повтор слова в том же формате в тот же день не даёт дополнительных XP. Спряжение — отдельное упражнение. Баллы назначаются сервером, повторная отправка ответа не удваивает результат. Серия считается по календарю Europe/Madrid, день с ответами поддерживает серию; пропуск прерывает её, но XP сохраняются. Серия есть общая и отдельная для каждого формата.

История ответов и новые метаданные сессий сохраняются в SQLite и экспорте. Старые записи сохраняются: формат восстанавливается только по однозначным идентификаторам mixed:/lingva:, неоднозначные self: остаются в общем прогрессе. XP задним числом не выдумываются. После перезапуска прерванную сессию нужно начать заново; уже записанные интервалы, ответы, XP и история не теряются.

Во вкладке «План» расположена доска по рисунку преподавателя: слева месяц и восемь аспектов языка, справа отдельные поля «Скиллы», «Темы», «Ситуации». Ниже — общий текст точки А, дата исходной проверки, точка Б (желание ученика), критерии успеха и ежемесячная рефлексия. Ученик выбирает ровно два разных аспекта; третий флажок блокируется интерфейсом и проверяется сервером. Точку А можно заполнить произвольными заметками, результатами тестов и наблюдениями. Все поля кроме месяца, двух аспектов и желания ученика можно дополнить позже. Критерии успеха заполняет ученик: у преподавателя это поле доступно для чтения, а сервер запрещает подмену критерия в преподавательском запросе.

Период начинается в дату первого сохранения плана по Europe/Madrid. Следующий запрос — через календарный месяц, с переносом на последний день короткого месяца (31 января → 28/29 февраля). Дата точки А и редактирование текущего плана не сдвигают срок. Пока текущий план действует, его можно менять; следующий создаётся после окончания периода. Название месяца — подпись для ученика, оно не заменяет фактические даты периода. История сохраняет реальные записи, пропущенные месяцы не заполняются вымышленными целями.

У ученика при входе в любую вкладку без действующего плана появляется закрываемое окно «Какой план у тебя на этот месяц?». После окончания периода оно предлагает написать рефлексию и составить новый план. После сохранения итогов появляется вопрос о следующем плане. «Позже» закрывает окно на текущий заход, незаполненный план будет предложен при следующем входе/обновлении. День пересчитывается раз в минуту и при возвращении в окно. Почтовые и push-уведомления не отправляются.

Рефлексию можно заполнить вручную в любой момент, в том числе до конца месяца или позже из архива. Подсказка предлагает описать изменения в 2–3 предложениях и повторить исходный тест, если он был. В «Плане на месяц» и «Ежемесячной рефлексии» есть «Посмотреть архив»: прошлые периоды показаны с целями слева и рефлексией справа, подробностями точки А, скиллов, тем, ситуаций и критериев. Результаты прежних тестов сохраняются. Закончившийся период появляется в архиве автоматически, даже если следующий план или рефлексия ещё не заполнены. Старый план в архиве не редактируется, собственную рефлексию ученик может уточнять.

Новые записи имеют layoutVersion: 2; старые месячные планы и их примеры/баллы читаются без удаления и входят в тот же архив. Для старых периодов сохранены ранее назначенные даты. monthlyPlans входят в резервную копию и переживают перезапуск. Общий старый план курса остаётся в данных и экспорте, его отдельный блок больше не выводится. Ученик работает только со своим кабинетом; создание, изменение и рефлексия защищены проверками владельца, версией записи и обработкой повторных запросов. Словарь, интервалы повторения, XP и статистика не изменяются. ИИ для этой доски не требуется.
