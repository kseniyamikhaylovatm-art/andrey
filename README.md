# Mi español · Андрей и Таня

Пошаговое пробное размещение сайта: [DEPLOY.md](DEPLOY.md). `render.yaml` использует бесплатный тариф Render с временным хранилищем: прогресс может сброситься после сна/перезапуска. Не вносите туда важные данные. Отдельный `render-persistent.yaml` — платный вариант для постоянного хранения, не применяется автоматически.

Первая рабочая версия персонального тренажёра по предоставленному ТЗ. Общие карточки, результаты, занятия и оплата для Андрея и Тани. Русский интерфейс, испанский учебный контент; адаптация для телефона и компьютера.

## Запуск

Нужен Node.js **24** (проверено на 24.19.0), npm и существующая копия репозитория. Дополнительный Git worktree не нужен: облачная задача уже изолирована.

```sh
cd /workspace/andrey
npm ci
npm run dev
```

Сервер по умолчанию слушает `127.0.0.1:3000`. Он обслуживает и интерфейс, и API; отдельные сервисы базы данных не нужны. Проверка работоспособности: `curl --fail http://127.0.0.1:3000/api/health`. Для разработки в другой среде путь к репозиторию может отличаться.

```sh
npm run build     # TypeScript и production-сборка интерфейса
npm test          # 13 тестов: логика, SQLite, HTTP, PDF, доступ
npm run test:e2e  # Chromium: основные действия и мобильная навигация
npm run test:production # После build: production-сервер, вход и перезапуск с сохранением данных
```

Для браузерных тестов используется `/usr/bin/chromium`. Другой путь можно указать через `CHROMIUM_PATH`. Если Chromium не установлен, установите поддерживаемый браузер Playwright и укажите путь. Браузерные тесты создают собственную временную SQLite-базу и не трогают пользовательские данные.

## Что работает

- **План:** цели по навыкам, темы, критерии успеха, счётчик состоявшихся встреч; редактирование преподавателем.
- **Кабинет:** действительная статистика, сводка по данным (без ИИ тоже), трудные фразы, фокус, задания со сроками, дневник реальной речи и доля избегания по неделям, материалы и заметки уроков.
- **Автоматизация:** четыре варианта перевода; примеры открываются после ответа. Интервалы 1–2–4–8–16–32 дня, после ошибки — 10 минут. Новые слова, повторение, фокус, темы, база с редактированием и включением отдельных фраз. Тренировка дня связывает карточки, письмо форм, речь и слух.
- **Примеры под карточкой:** после ответа открываются шесть вкладок: Presente, ir a + infinitivo, estoy + gerundio, pretérito perfecto, indefinido и imperfecto. В каждой — испанский пример, русский перевод, обычная и медленная озвучка; у поддерживаемых глаголов дополнительно шесть форм. Для всех 24 стартовых карточек есть подготовленные примеры без API. Существительные не спрягаются; для состояний не создаётся искусственное estoy estando. Можно добавить или исправить пример выбранного времени, сохранив остальные примеры и прогресс. Исходные примеры без метки времени остаются в раскрываемом разделе материалов. Для нового незнакомого слова пустые вкладки заполняются преподавателем или кнопкой «Дополнить с ИИ» при подключённом ключе; недостающие примеры не выдумываются автоматически.
- **Глаголы:** ручной выбор или ввод инфинитива, настоящее, три прошедших, герундий и будущее ir a + infinitivo, ввод шести форм, проверка ударений, таблица справа и исправления преподавателем. Проверенные стартовые формы 22 глаголов, включая неправильные и возвратный `escaparse`. Для других глаголов доступны ручное заполнение и генерация с Claude.
- **Речь:** монолог, пересказ, работа над ошибками, диалог; текст и браузерная диктовка, таймер; серверная история ответов и диалогов после успешной проверки. Диктовка — распознавание текста браузером, не оценка произношения и не сохранение аудиофайла.
- **Слух:** три стартовых задания с браузерной озвучкой и скрытым до ответа образцом; преподаватель может добавить прямую HTTPS-ссылку на запись. Открытый ответ сравнивается с образцом, а при подключённом Claude получает индивидуальную обратную связь. Открытые ответы не получают искусственную оценку «верно/неверно».
- **Прогресс:** настоящие попытки, точность, активность за 12 недель, темы, прогноз повторений, трудные фразы и времена.
- **Оплата:** пакеты по 12 встреч, оплаченные строки, состоявшиеся/отменённые встречи, остаток и долг в занятиях. Отмена не расходует пакет. Приложение не принимает деньги.
- **PDF карточек без ИИ:** кнопка «Загрузить PDF карточек» в «Автоматизации» и «Кабинете». Строки «испанское слово — русский перевод» создают до 1000 карточек за раз. Поддерживаются тире/дефис, фразы и вставка списка текстом; перед сохранением — исправление и удаление отдельных строк. Неразобранные строки показаны явно. Повторы пропускаются без замены перевода и прогресса. Этот режим не создаёт занятия и не требует API-ключа.
- **PDF материалов урока:** извлечение текста из текстового PDF до 15 МБ / 150 страниц; выбор страниц, обработка фрагмента Claude, редактируемый предпросмотр и явное подтверждение. Повторные фразы не дублируются, сохраняются источник, регистр и текст урока. Грубые фразы при импорте по умолчанию выключены. Сканированным PDF предварительно нужен OCR.

Стартовые 24 карточки и три задания на слух помечены как учебные примеры. Реальные занятия, оплаты, ответы и прогресс при первом запуске **пустые**. Материал «Clanes» не был предоставлен и не выдаётся за загруженный.

## Подключение Claude

Скопируйте `.env.example` в локальный `.env` и задайте `ANTHROPIC_API_KEY` безопасным способом на сервере. Не сохраняйте ключ в Git и не вводите его в чат. По умолчанию выбран `claude-sonnet-4-5`; `ANTHROPIC_MODEL` позволяет выбрать доступную вашей организации модель.

Ключ используется только сервером. В интерфейс он не передаётся. Нужен HTTPS-доступ к **api.anthropic.com**; npm использует **registry.npmjs.org**. В управляемой облачной среде сохраняется унаследованный HTTP(S)-прокси и доверие TLS; AI-запросы идут через `EnvHttpProxyAgent`. Проверка сертификатов не отключается.

Без ключа ИИ-действия обозначены как недоступные. Приложение не подменяет ответ Claude шаблонной «проверкой». Карточки, стартовые глаголы, редактирование, статистика, дневник, учёт, массовый импорт пар «слово — перевод» и локальное чтение PDF работают независимо от API. Индивидуальный разбор речи, диалоги, генерация новых таблиц/карточек и автоматический разбор документов требуют ключа. Ответы Claude в этой среде не проверены: ключ не предоставлен.

На сервере действует лимит 80 AI-запросов в час на общее пространство и тайм-аут запроса 90 секунд. Преподавателю следует проверять автоматически созданные формы и материалы перед использованием.

## Хранение и общий доступ

Данные находятся в `data/mi-espanol.sqlite` (WAL, транзакции). `DATA_DIR` задаёт другой каталог. **Это общий серверный файл**, а не отдельное хранилище браузера: пользователи одного сервера видят одно пространство. Незавершённые тексты речи сохраняются на текущем устройстве; проверенные ответы — на сервере.

Для размещения нужен **один Node-процесс и постоянный диск**. Публикация только папки `dist` не подходит: API и база необходимы. Не запускайте несколько экземпляров с независимыми дисками. Регулярно делайте согласованную резервную копию SQLite (например, через SQLite backup API). В интерфейсе также есть скачивание JSON-экспорта. Автоматического восстановления JSON через интерфейс пока нет.

Production:

```sh
npm ci
npm run build
# Переменные должны быть заданы безопасно в среде размещения:
# APP_ACCESS_CODE — общий код не короче 10 символов
# SESSION_SECRET — случайный секрет не короче 32 символов
# DATA_DIR — каталог постоянного диска
# HOST=0.0.0.0 — только за вашим HTTPS-прокси
npm start
```

Production-сервер откажется запускаться без кода и секрета. Доступ общий для учеников и преподавателя, без переключателя ролей, как в ТЗ. Сессия хранится в подписанной HttpOnly/SameSite=Strict cookie, в production — Secure. Все рабочие API и экспорт защищены. Код доступа вводится пользователями в приложении; не используйте для него proxy-placeholder: нужен настоящий секрет локального процесса. Для тестирования по HTTP используйте `npm run dev`; публичный доступ размещайте через HTTPS.

Это самостоятельное веб-приложение. Оно **не опубликовано в Claude Artifacts**: команда Claude сама по себе не размещает Node-сервер и SQLite и не предоставляет приложению Claude API. После размещения можно делиться HTTPS-ссылкой на приложение. Для нативной публикации внутри Claude нужен отдельный поддерживаемый механизм интеграции. Сайт-образец по предоставленной ссылке вернул 403; дизайн реализован по описанию из ТЗ, без заявления о точном визуальном совпадении.
