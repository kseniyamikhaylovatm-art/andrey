# Подключение ИИ к платформе

ИИ оплачивается отдельно от Render. Настройки сервера и диска уже сохраняют кабинеты; ключ включает автоперевод, примеры, диалоги и разбор ответов.

1. Откройте https://console.anthropic.com/ и войдите или создайте аккаунт.
2. В разделе Billing настройте оплату API и пополните баланс. Условия и сумму покажет Anthropic.
3. Откройте API Keys → Create Key. Скопируйте полученный ключ и сохраните у себя.
4. В Render откройте andrey → Environment → Edit → Add variable.
5. В поле Key укажите `ANTHROPIC_API_KEY`. В Value вставьте именно ключ, скопированный из Anthropic. Случайное значение кнопки Generate здесь не подходит.
6. Нажмите Save, rebuild, and deploy. Дождитесь Live, обновите платформу через ⌘ + Shift + R.
7. В кабинете преподавателя откройте Мои ученики → Имя и уровень. Выберите уровень ученика A1–C2 и сохраните.
8. Откройте кабинет ученика → Слова. Нажмите на слово без примера: приложение запросит пример для текущего уровня и сохранит его. Последующие открытия используют сохранённый пример. Для проверки автоперевода введите новое испанское слово без перевода и добавьте его.

Ключ вводится только в Render: его не нужно отправлять в чат или сохранять в GitHub. Существующие TEACHER_ACCESS_CODE, SESSION_SECRET, DATA_DIR и остальные настройки сохраняются.

Если после настройки перевод не работает, проверьте последний Deploy и уведомление приложения. Наличие переменной ещё не подтверждает, что ключ действителен и на API есть средства. Для проверки ошибки можно передать текст сообщения, скрыв ключ.

Уровень хранится в плане конкретного ученика и отображается в карточке профиля. Он передаётся во все ИИ-запросы учебного контента. Новые примеры по нажатию помечаются уровнем; после смены уровня приложение может создать новый пример. Вручную добавленные преподавателем примеры сохраняются. Автоматические примеры следует проверять и при необходимости править карандашом.
