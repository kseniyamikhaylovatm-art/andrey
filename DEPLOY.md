# Как бесплатно попробовать сайт по ссылке

Основной `render.yaml` теперь описывает **бесплатный пробный** сервер на [Render](https://render.com). Аккаунт Claude и API-ключ для проверки карточек, глаголов и интерфейса не нужны.

## Что подготовлено

В `render.yaml` выбран `plan: free`, нет платного диска и других платных ресурсов. Сервер хранит тестовый прогресс во временной папке `/tmp/mi-espanol-demo`. Общий код входа и секрет сессии генерируются автоматически; секретных значений в файлах нет.

Это проба интерфейса и тренировок. Бесплатный сервер может засыпать при отсутствии посещений. Первое открытие после паузы может занимать больше времени; прогресс может сбрасываться после сна, перезапуска или нового размещения. В приложении показывается сообщение «Пробная версия». Настоящие оплаты, важные материалы и единственный экземпляр записей в этот вариант не вносите.

Конкретные условия бесплатного тарифа проверяются в интерфейсе Render. Если выбранный способ создания сервиса показывает ненулевую стоимость или требует платного тарифа, не подтверждайте создание: проверьте именно бесплатный вариант. Официальная документация из рабочего окружения вернула 403, поэтому актуальные квоты, требование карты и доступность бесплатного тарифа для вашего аккаунта не подтверждены. Фактическое размещение на Render ещё не выполнено.

## Последовательность

1. Зарегистрируйтесь на Render или войдите через GitHub. Нужен аккаунт с доступом к `kseniyamikhaylovatm-art/andrey`.
2. Перед размещением убедитесь, что код приложения доступен в GitHub-репозитории и в выбранной ветке есть package.json и render.yaml. Render загружает код из GitHub, а не из рабочего окружения ассистента.
3. После загрузки кода создайте сервис из репозитория. Если доступны **New → Blueprint**, используйте основной `render.yaml`. При ручном создании выберите **New → Web Service**, среду **Node**, тариф **Free** и настройки ниже. Если Blueprint не позволяет бесплатное создание, используйте ручной Web Service.
4. Дождитесь статуса **Live**. Render покажет HTTPS-ссылку сайта. Адрес заранее не назначен.
5. В **Environment** посмотрите автоматически созданный `APP_ACCESS_CODE` (Blueprint) или укажите собственный общий код от 10 символов (ручное создание). Передайте код ученикам лично. `SESSION_SECRET` оставьте случайным и секретным; значения этих переменных не нужны ассистенту.
6. Откройте сайт, введите код и проверьте карточки и глаголы. На другом устройстве тот же сайт видит общие данные, пока живёт этот экземпляр сервера. Длительную сохранность прогресса бесплатный вариант не гарантирует.

## При ручном создании Web Service

- Runtime: **Node**.
- Instance type: **Free**. Постоянный диск не добавлять.
- Build command: `npm ci --include=dev --no-audit --no-fund && npm run build`.
- Start command: `npm start`.
- Health check: `/api/health`.
- Переменные: `NODE_VERSION=24.19.0`, `NODE_ENV=production`, `HOST=0.0.0.0`, `DATA_DIR=/tmp/mi-espanol-demo`, `DEMO_MODE=true`.
- `APP_ACCESS_CODE`: придумайте общий код от 10 символов и введите только в Render.
- `SESSION_SECRET`: используйте генератор случайного значения Render, если доступен, или секрет из генератора паролей длиной не менее 32 символов. Не используйте пример из документации или чужой код.

## Когда понадобится постоянный прогресс

Отдельный `render-persistent.yaml` описывает платный сервер с диском. Он не применяется при запуске основного бесплатного `render.yaml`. Переход на него требует отдельного решения и проверки стоимости. Ещё один будущий вариант — внешняя база с подходящим бесплатным тарифом; текущий код использует SQLite и такого подключения пока не содержит.

## ИИ — отдельный последующий шаг

Для диалогов, разбора рассказов и автоматической обработки PDF нужна настройка API. Текущая интеграция — Anthropic: `ANTHROPIC_API_KEY` добавляется только в **Environment** сервера. Бесплатное размещение сайта не делает использование платного API бесплатным. Для первого знакомства ИИ можно не подключать; приложение явно показывает, какие действия пока недоступны.
